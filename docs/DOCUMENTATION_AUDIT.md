## 整理决定

- 原 `.md` 路径保留为中文，英文使用 `.en.md`；旧路径和 heading 片段继续作为入口。维护页面不堆叠两种语言。
- 用任务索引区分入门教程、操作指南、原理说明、参考资料。历史证据独立标记，不为目录形式而搬动所有旧路径。
- 工件版本、流程 schema、文件 wrapper、SQL revision、发布标签和证据提交分别说明；当前源码不代表旧标签的能力。
- 模块介绍聚焦可运行步骤和明确边界，被整理的旧说明逐字节放入[历史归档](history/README.md)，登记来源和 SHA-256。原始证据保留当时语言，双语入口提供同等范围说明与相同访问路径。
- 接口以真实 controller、DTO、目录及测试为准。独立端和若依分别提供离线 OpenAPI 3.1，不暗示新增服务路由或 Swagger UI。

## 维护门禁

自动检查证明结构和部分可执行契约，不能代替翻译质量或所有运行时不变量的审阅。离线链接检查不声称外部 URL 可用。真实 HTTP 示例使用新打包的隔离后端；浏览器和真实数据库须看各自精确提交的任务。本地启动失败或数据库跳过必须在交付说明中保留。
