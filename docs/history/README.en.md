## What belongs here

Current instructions live in the [documentation index](../README.en.md). This directory retains byte-exact earlier document sources, including original test reports and superseded module guides. They are source artifacts, not maintained mixed-language pages. Each historical reader page has a Chinese/English counterpart with the same scope and access to the original material.

Dates, counts, blocked checks and candidate status in an original record describe that checkpoint only. Do not rewrite them as current acceptance. The registry records exact Git source revisions and checks archive bytes against their SHA-256 values. Editing a current guide does not alter its historical source.
